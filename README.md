# Matter — Organize what matters.

Your personal tasks, goals, habits, money and notes in one calm workspace.

![Matter Preview](https://img.shields.io/badge/version-1.0-amber) ![No Login](https://img.shields.io/badge/data-local--only-cream) ![Calm](https://img.shields.io/badge/vibe-calm%20not%20hustle-brown)

### What is Matter?
Matter is a calm personal organizer template — not another toxic productivity app. It's where your matters live: tasks, goals, habits, budget, notes, library, calendar, projects.

Built for people who want to move *dahan-dahan, pero tuloy-tuloy* — slowly but surely.

### Features
- **Dashboard** — Today's overview, ready to work
- **Planner** — Weekly tasks
- **Notes** — Fast capture
- **Goals** — OKR style with why it matters
- **Habits** — Streaks without guilt
- **Budget** — ₱ / $ friendly, calm money
- **Library** — Books, articles, courses
- **Calendar** — Monthly calm view
- **Projects** — Todo / Doing / Done board

### No login. Your data stays in your browser.
Local-first, privacy-focused. Export anytime from Backup.

### Tech
Single HTML files, vanilla React (no build needed), warm minimal design — espresso #1e1712, cream #faf6f0, amber #d9a679.

### Get Started
1. Download `matter-v1.0-complete.zip`
2. Unzip
3. Open `index.html`
4. Or host on GitHub Pages
